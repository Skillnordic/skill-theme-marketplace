# Skill Theme for Moodle – issue tracker

This is where you report bugs and suggest improvements for **Skill Theme** (`theme_skill`), the Moodle theme from
Skill Nordic AS. The theme itself is available in the Moodle Marketplace. This repository holds no code.

## Report a bug

[Open a new issue](../../issues/new) and include:

- your Moodle version (for example 4.5.3 or 5.1);
- the Skill Theme version (Site administration → Plugins → Plugins overview);
- the browser and device;
- what you did, what you expected, and what happened;
- a screenshot, if it helps.

Please do not post passwords, connection keys or personal data about your users in an issue. Issues here are public.

## Suggest an improvement

Open an issue and describe what you would like the theme to do, and why.

## Support

Customers can also contact us at **support@skillnordic.no**. We answer within two working days.
